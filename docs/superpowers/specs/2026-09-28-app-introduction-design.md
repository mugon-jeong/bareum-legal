# 바름 앱 소개 사이트

사용자 승인: 출시 전에는 소개만 제공하며 출시 후 App Store 다운로드 유도로 전환한다. 실제 앱 화면을 중심으로 순서, 성분 관계 그래프·트리맵·피부층 모식도, 위젯·실시간 현황·다이나믹 아일랜드, Apple Watch, 기록을 소개한다. ThreeUI의 Perspective UI를 입체 화면 배치와 절제된 모션의 참고로 삼는다.

## 구성
- 홈 첫 화면: “가진 화장품, 바르는 순서부터.”와 실제 순서 화면. App Store 출시 예정 상태와 기능 소개 앵커.
- 순서: 아침·저녁 루틴과 제품 담기 흐름. 앱 구현 범위 내 설명.
- 그래프: 성분 관계와 근거를 살펴보는 실제 그래프 화면. 효능은 성분에 귀속하며 연결을 효능·안전성 보장으로 설명하지 않는다.
- 위젯: 오늘 순서와 연속 기록, 홈·잠금 화면 지원을 실제 구현 기준으로 소개. 앱에서 루틴을 준비한 뒤 이용한다는 조건을 명시.
- 성분 구성: 공식 용도·검증된 효능 기준의 트리맵. 면적은 고유 성분 수이며 함량이 아니다.
- 피부층 UI: 시점별 성분 이동 모식도와 성분 상세. 실제 흡수량·효과 측정으로 표현하지 않는다.
- 실시간 현황: 잠금 화면과 다이나믹 아일랜드의 제품·진행·대기시간·체크 기능.
- Apple Watch: 아침·저녁 루틴, 현재 단계·대기시간, 체크·건너뛰기, 상세와 iPhone 동기화.
- 기록: 일별 루틴 기록 화면과 출시 예정 안내.
- 하단: 기존 개인정보처리방침·이용약관·고객지원.

## 구현
기존 Jekyll과 Cloudflare Workers Static Assets를 유지한다. 홈만 전용 Liquid 레이아웃, CSS, 작은 JS로 만든다. 폼·사용자 데이터 수집·백엔드·새 프레임워크는 필요 없다. 다운로드 URL은 단일 설정값이며 미지정 상태에서는 가짜 다운로드 버튼을 만들지 않는다. 기존 법적 문서 내용과 URL, GitHub Pages 리다이렉트는 보존한다.

밝은 회백색과 앱의 초록·보라색을 사용한다. 모바일 우선, 키보드 접근성, reduced motion, JS 없는 상태에서도 읽을 수 있는 콘텐츠를 보장한다. 스크린샷은 실제 앱의 데모 데이터 화면이며 출처와 캡처 방식을 기록한다. ThreeUI 소스나 유료 리소스는 복사하지 않는다.

## 검증과 완료 범위
Jekyll Cloudflare/기본 빌드, Wrangler 패키징, 모바일/데스크톱 화면, 앵커·이미지·기존 문서 링크, 가로 넘침, 접근성, reduced motion을 확인한다. 로컬 미리보기까지 완성하며 운영 배포·머지는 별도 요청 범위다.
