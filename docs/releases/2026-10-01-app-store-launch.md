# App Store 출시 상태를 소개 사이트에 반영

2026-10-01 한국 App Store의 [바름: 올바른 스킨케어](https://apps.apple.com/kr/app/id6807600225) 공개 페이지를 확인하고 https://bareum.app 에 배포했다.

- `_config.yml`에 App Store URL을 설정해 헤더·첫 화면·하단 다운로드 링크 3곳을 활성화했다.
- 홈 메타정보의 출시 예정 문구와 푸터의 출시 전 안내를 갱신했다.
- 모바일 헤더는 브랜드·다운로드와 기능 메뉴를 두 줄로 배치해 글자 줄바꿈을 방지했다.
- 원격 main `8d276d8`을 먼저 동기화했으며 기존 AI 루틴 소개·정책·지원 본문과 화면 자료를 유지했다. 이번 작업에서 출시 빌드 스크린샷을 새로 촬영하지 않았다.

## 배포 및 검증

- Cloudflare MCP 정적 파일 직접 업로드. Worker: `bareum-legal`.
- 최종 deployment ID: `687da01aff714670a82203307d91081f`.
- Jekyll 빌드·Wrangler dry-run·JavaScript 구문·diff 공백 검사 통과.
- 브라우저 360/390/768/1440px에서 다운로드 링크 3곳, 가로 넘침 없음 확인. 모바일 헤더와 첫 화면 육안 확인.
- 운영 홈·CSS·개인정보처리방침·이용약관·고객지원이 빌드 결과와 일치. 문서 4개 HTTP 200.
