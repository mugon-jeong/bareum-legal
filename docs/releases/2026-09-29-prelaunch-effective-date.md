# 출시 전 약관·방침 시행일 정리

출시 전이라는 운영자 확인에 따라 이용약관과 개인정보처리방침의 시행 예정일·개정 공지·종전 문서 적용 안내를 제거하고 시행일을 2026-09-29로 정리했다. 별도 동의가 필요한 처리의 사전 동의 원칙은 유지한다.

Jekyll 빌드와 Wrangler dry-run, 생성 HTML 날짜 검사, 운영 48개 파일 HTTP 200·바이트 일치를 확인했다. Cloudflare 버전 `21264a0b-3be6-4733-891b-19ae27ae144a`로 배포했다. 문서 변경이며 동의 데이터·수집·발송 기능은 변경하지 않았다.
