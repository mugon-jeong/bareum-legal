# bareum-legal

iOS 앱 **바름(BAREUM)** 의 개인정보처리방침·이용약관 정본.

GitHub Pages 로 게시되며, 앱과 App Store Connect 가 이 URL 을 가리킨다.

| 문서 | URL |
|---|---|
| 개인정보처리방침 | https://mugon-jeong.github.io/bareum-legal/privacy/ |
| 이용약관 | https://mugon-jeong.github.io/bareum-legal/terms/ |

**여기가 정본이다.** 앱 저장소에 사본을 두지 않는다 — 앱은 URL 만 안다.
문서를 고치면 시행일과 개정일을 같이 올리고, 이용자에게 불리한 변경은 30일 전에 공지한다.
